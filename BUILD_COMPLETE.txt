🏗️ SYSTEM ARCHITECTURE
======================

Data Flow Pipeline:
  
  FastF1 API
       ↓
  DataIngestionAgent (fetches telemetry)
       ↓
  CSV Files (telemetry data)
       ↓
  OptimizationAgent (finds fastest lap)
       ↓
  CSV Files (optimal line benchmark)
       ↓
  AnalysisAgent (Gemini API)
       ↓
  JSON Files (insights + timestamps)
       ↓
  CommentaryAgent (ElevenLabs API)
       ↓
  CSV + MP3 (timed commentary)
       ↓
  Flask Data Server
       ↓
  Unity Replay System
       ↓
  Interactive Visualization + Audio

🚀 QUICK START
==============

1. Setup (1 minute):
   $ bash setup.sh
   $ # Edit config/.env with API keys

2. Generate Data (2-3 minutes):
   $ python orchestrator.py --year 2023 --grand-prix Australian --drivers VER,ALO --skip-audio

3. Start Server:
   $ python data_server.py

4. Run Unity Replay:
   • Open Unity project
   • Attach F1ReplaySystem.cs to game object
   • Press Play

For detailed instructions, see: QUICKSTART.md

🔌 API ENDPOINTS
================

When running data_server.py:

http://localhost:5000/api/drivers              - Available drivers
http://localhost:5000/api/telemetry/<driver>   - Raw telemetry
http://localhost:5000/api/optimal-line/<driver> - Optimal line
http://localhost:5000/api/analysis/<driver>    - AI insights
http://localhost:5000/api/commentary/<driver>  - Timed commentary
http://localhost:5000/api/replay-data/<driver> - Complete replay package
http://localhost:5000/api/race-summary         - Race overview

🐛 COMMON ISSUES & FIXES
=======================

Issue: "FastF1 timeout"
Fix: Wait 30 seconds (API rate limit), try again

Issue: "Gemini API error"
Fix: Check API key in config/.env, verify API is enabled

Issue: "No telemetry in Unity"
Fix: Verify CSV files exist in data/, check file paths

Issue: "Server won't start"
Fix: Check if port 5000 is free: lsof -i :5000
